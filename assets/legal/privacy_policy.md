# 개인정보처리방침

본 개인정보처리방침은 「주차기억」(이하 '서비스') 가 「개인정보 보호법」 제30조에 따라 이용자의 개인정보를 보호하고 이와 관련된 고충을 신속하고 원활하게 처리할 수 있도록 다음과 같이 수립·공개합니다.

**시행일자: 2026년 5월 24일**


## 1. 수집하는 개인정보 항목 및 수집 방법

서비스는 다음의 개인정보 항목을 수집합니다. 수집된 정보는 모두 이용자의 단말기 내부 저장 공간에만 보관되며, 외부 서버로 전송·축적하지 않습니다.

### 1.1 자동으로 수집되는 정보

| 항목 | 수집 시점 | 저장 위치 | 비고 |
|---|---|---|---|
| GPS 좌표 (위도/경도) | 주차 사진 촬영 시 1회 | 단말기 내부 (앱 전용 저장소) | 위치정보법 적용 |
| 주차 시각 | 사진 촬영 시 | 단말기 내부 | |
| 주차 사진 | 사용자 직접 촬영 | 단말기 내부 (EXIF GPS 제거 후 저장) | |
| 도로명 주소 | GPS 좌표 → 카카오 역지오코딩 변환 결과 | 단말기 내부 | |
| 차량 Bluetooth MAC 주소 | 사용자가 [수동 차량 등록] 시 1회 | 단말기 내부 (AES-256 암호화) | 자동 알림용 |
| 차량 Bluetooth 기기명 | 사용자가 [수동 차량 등록] 시 1회 | 단말기 내부 (AES-256 암호화) | |

### 1.2 수집 방법

- 단말기 OS의 표준 권한 시스템을 통한 사용자의 명시적 동의
- 이용자가 앱 내에서 직접 입력하거나 촬영한 정보


## 2. 개인정보의 수집 및 이용목적

서비스는 수집한 개인정보를 다음의 목적을 위해 활용합니다.

1. **주차 위치 기록 및 조회**: GPS 좌표·주소·사진을 단말기에 저장하여 사용자가 자신의 주차 위치를 다시 확인할 수 있도록 합니다.
2. **자동 주차 알림**: 차량 Bluetooth 연결 해제를 감지하여 사용자에게 주차 알림을 발송합니다.
3. **위젯 표시**: 홈 화면 위젯에 최근 주차 정보를 표시합니다.
4. **사용자 직접 공유**: 사용자가 [공유] 버튼을 통해 카카오톡 등 외부 앱에 직접 전달할 수 있습니다 (자동 전송 없음).


## 3. 개인정보의 보유 및 이용 기간

- 수집된 개인정보는 **이용자의 단말기 내부에만 보관**되며, 서비스 제공자는 어떠한 정보도 외부 서버에 저장하지 않습니다.
- 이용자가 앱을 삭제하거나 설정에서 [데이터 삭제]를 선택하면 모든 데이터가 즉시 삭제됩니다.
- 주차 이력은 최대 100건까지 단말기에 보관되며, 100건을 초과할 경우 가장 오래된 항목이 자동 삭제됩니다.


## 4. 개인정보의 제3자 제공

서비스는 이용자의 개인정보를 외부에 제공하지 않습니다. 단, 다음의 경우는 예외로 합니다.

1. **이용자가 직접 공유하는 경우**: [카카오톡으로 공유] 버튼을 누른 경우, 해당 정보는 카카오톡으로 전달됩니다.
2. **법령에 따른 요청**: 수사기관이 법령의 절차에 따라 요청한 경우.


## 5. 개인정보 처리 위탁

서비스는 일부 기능 제공을 위해 다음의 외부 서비스를 활용하나, 개인정보 자체를 위탁 처리하지는 않습니다.

| 위탁받는 자 | 위탁 업무 | 전송 정보 |
|---|---|---|
| (주)카카오 | 좌표 → 한국어 도로명주소 변환 | GPS 좌표 (개인 식별 정보 없음) |
| Google LLC (AdMob) | 배너 광고 게재 | 광고 식별자 (Android Ad ID), 대략적 위치(IP 기반 국가 단위), 기기/네트워크 정보 — 모두 비식별 |
| Google LLC (Play Billing) | 광고 제거 인앱 결제 | Google 계정 식별자 (Google 측에서 직접 처리) |

### 5.1 광고 식별자 및 개인화 광고 안내

- **광고 식별자 재설정·삭제**: Android 단말기의 [설정 > Google > 광고]에서 광고 ID 를 재설정하거나 삭제할 수 있습니다.
- **개인화 광고 옵트아웃**: 동일 메뉴의 [광고 맞춤설정 선택 해제]를 통해 관심 기반 광고를 거부할 수 있습니다.
- **광고 제거 결제**: 앱 [설정 > 광고 제거 (₩1,900)] 에서 광고 자체를 영구 제거할 수 있습니다.
- **Google 광고 정책 전문**: https://policies.google.com/technologies/ads
- EEA/UK 지역 사용자의 경우, 앱 최초 실행 시 GDPR 동의 양식(UMP)이 표시되며 동의 거부 시 비개인화 광고만 송출됩니다.


## 6. 정보주체와 법정대리인의 권리·의무 및 행사 방법

이용자는 언제든지 다음의 권리를 행사할 수 있습니다.

- **열람**: 앱 내 주차 이력 화면에서 직접 확인
- **삭제**: 앱 설정의 [데이터 삭제] 또는 앱 자체 삭제
- **권한 철회**: 단말기 OS 설정에서 카메라/위치/Bluetooth/알림 권한 개별 해제

서비스는 단말기 외부에 개인정보를 보관하지 않으므로, 별도의 정정·삭제 요청을 처리할 데이터를 보유하고 있지 않습니다.


## 7. 개인정보의 안전성 확보 조치

서비스는 개인정보의 안전성 확보를 위해 다음의 조치를 취하고 있습니다.

1. **암호화 저장**: 차량 Bluetooth MAC 주소·기기명은 Android Keystore 기반 AES-256-GCM 암호화로 저장
2. **백업 차단**: Google 클라우드 자동 백업 비활성화 (`allowBackup=false`)
3. **HTTPS 통신**: 외부 API 호출 시 평문 통신(HTTP) 차단 (`usesCleartextTraffic=false`)
4. **로그 제거**: 운영 배포(Release) 빌드에서 모든 디버그 로그 자동 제거
5. **권한 가드**: Bluetooth 관련 시스템 이벤트는 OS 시스템 권한 보유 주체만 수신 가능
6. **코드 난독화**: R8/ProGuard 를 통한 클래스·메서드 난독화 적용
7. **EXIF 제거**: 사진 저장 시 GPS 등 메타데이터를 자동으로 제거
